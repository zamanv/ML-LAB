EXPERIMENT 06
=================================================================
QUESTION
---------
Implement a Naive Bayes classifier to categorize text documents into
topics using the 20 Newsgroups dataset. Compare the performance of
Multinomial Naive Bayes with Bernoulli Naive Bayes.

Tasks:
  * Load and preprocess the 20 Newsgroups dataset.
  * Implement Multinomial Naive Bayes and Bernoulli Naive Bayes
    classifiers.
  * Evaluate and compare performance using accuracy and F1-score.
  * Discuss the strengths and weaknesses of each variant for text
    classification.

=================================================================
ALGORITHM
---------
1. Load the 20 Newsgroups dataset, restricting to 4 balanced
   categories (alt.atheism, comp.graphics, sci.med,
   soc.religion.christian) and removing headers, footers and quotes
   to avoid leakage.
2. Preprocess text:
   - Tokenize and build a vocabulary with CountVectorizer using
     English stop-word removal.
   - Multinomial NB uses raw term counts (word frequencies).
   - Bernoulli NB uses a binary occurrence matrix (word present or
     not).
3. Naive Bayes:
   - Uses Bayes' theorem: P(class | document) proportional to
     P(class) * product P(word | class).
   - Multinomial models the count of each word (good for longer
     documents).
   - Bernoulli models the presence/absence of each word and
     explicitly penalizes absent words.
   - Laplace smoothing (alpha = 1) avoids zero probabilities.
4. Predict topics for the test set and compute accuracy, weighted
   F1-score, and per-class precision/recall/F1.
5. Compare the two variants with a bar chart.

=================================================================
RESULT ANALYSIS
---------------
OBSERVED OUTPUT (typical run):
  Train documents: 2257 | Test documents: 1502
  Multinomial NB -> Accuracy: 0.9210  F1 (weighted): 0.9207
  Bernoulli NB   -> Accuracy: 0.8828  F1 (weighted): 0.8815

ANALYSIS:
  * Multinomial NB outperforms Bernoulli NB on this task (about 0.92
    vs 0.88 accuracy). Multinomial uses word-frequency information,
    which is highly informative in newsgroup posts: repeated
    technical or topical terms strongly signal a category.
  * Bernoulli NB loses accuracy because it discards frequency and,
    more importantly, includes a penalty term for every vocabulary
    word that is ABSENT from a document. In long documents most
    vocabulary words are absent, so the "absent word" evidence
    dominates and can wash out the true signal.
  * Both models are extremely fast to train and predict (a single
    pass over the count matrix), and both handle high-dimensional
    sparse text data gracefully.
  * Per-class F1 is consistently high across the four categories,
    confirming the models separate clearly distinct topics well;
    confusions are mostly between the two religion-related classes
    (alt.atheism vs soc.religion.christian) which share vocabulary.

CONCLUSION:
  For document-topic classification with word counts, Multinomial
  Naive Bayes is the better choice. Bernoulli NB is preferable only
  for short texts or binary bag-of-words settings where presence
  rather than frequency matters. Both are strong, cheap baselines
  whose main weakness is the naive independence assumption between
  words.

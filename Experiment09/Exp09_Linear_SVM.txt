EXPERIMENT 09
=================================================================
QUESTION
---------
Implement a Linear Support Vector Machine (SVM) to classify the Iris
dataset. Visualize the decision boundary and discuss how the margin
is determined.

  * Load and preprocess the Iris dataset.
  * Implement a Linear SVM for binary classification (Setosa vs
    Non-Setosa).
  * Visualize the decision boundary and margin.
  * Discuss the concept of the margin and how it influences
    classification.

=================================================================
ALGORITHM
---------
1. Load the Iris dataset; use the first two features (sepal length,
   sepal width) for 2-D visualization; binarize the target as
   Setosa (1) vs Non-Setosa (0).
2. Preprocess: standardize features (zero mean, unit variance) and
   split 80/20 train/test.
3. Linear SVM (hinge loss + L2 penalty):
   - Objective to minimize:  1/2 * ||w||^2  +  C * sum max(0,
     1 - y_i (w.x_i + b))
   - Hard-margin case: maximize the margin m = 2 / ||w|| by
     minimizing ||w|| subject to all points being correctly on the
     correct side.
   - Soft-margin: slack variables allow a few misclassifications,
     controlled by the trade-off parameter C. Larger C -> smaller
     margin but fewer slack errors.
   - The solution depends only on the support vectors (the training
     points lying on or inside the margin).
4. Evaluate accuracy and plot the decision boundary (z=0), the two
   margin hyperplanes (z=+-1), and highlight the support vectors.

=================================================================
RESULT ANALYSIS
---------------
OBSERVED OUTPUT (typical run):
  Test Accuracy: 1.0000
  Weight vector w: [2.29 -1.88]
  Intercept b: -0.31
  Margin width: 0.34
  Support vectors: 3

ANALYSIS:
  * The linear SVM classifies Setosa vs Non-Setosa perfectly (100%
    test accuracy) because Setosa is linearly separable from the
    other two species in the sepal-plane: all Setosa points lie on
    one side of the separating line.
  * How the margin is determined: the SVM finds the hyperplane
    w.x + b = 0 that maximizes the distance 2/||w|| between the two
    parallel margin planes w.x + b = 1 and w.x + b = -1. Minimizing
    ||w|| therefore maximizes the margin. The margin width equals
    2 / ||w|| (here ~0.34 in standardized units).
  * Only 3 training points are support vectors: exactly the closest
    non-Setosa and Setosa points that "pin" the margin. If any of
    them moves, the boundary moves - the rest of the data is
    irrelevant to the solution. This is what makes SVMs memory-
    efficient and robust.
  * Larger margin => better generalization (a wider safety zone), but
    with outliers the soft margin allows a controlled number of
    errors tuned by C. Here C=1 with separable data yields a
    maximal-margin separator.
  * The decision boundary is stable and robust to outliers far from
    the margin because non-support points do not affect the
    solution at all - an important advantage over logistic
    regression, which weights all points.

CONCLUSION:
  A linear SVM cleanly separates Setosa from Non-Setosa using only
  two features, achieving 100% accuracy. The margin concept provides
  both optimal separating geometry and theoretical bounds on
  generalization error; the classifier ends up depending only on the
  few support vectors that define the margin.

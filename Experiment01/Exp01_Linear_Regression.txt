EXPERIMENT 01
=================================================================
QUESTION
---------
Implement linear regression with one variable on the California
Housing dataset to predict housing prices based on a single feature
(e.g., the average number of rooms per dwelling).

Tasks:
  * Load and preprocess the dataset.
  * Implement linear regression using both gradient descent and the
    normal equation.
  * Evaluate model performance using MSE and R-squared.
  * Visualize the fitted line along with the data points.

=================================================================
ALGORITHM
---------
1. Load the California Housing dataset (fetch_california_housing).
2. Select the single feature 'AveRooms' (average rooms per dwelling)
   as X and 'MedHouseVal' (median house value) as target y.
3. Preprocess:
   - Handle missing values (none present in this dataset).
   - Split data into 80% train / 20% test (random_state=42).
   - Standardize the feature (mean 0, std 1) so gradient descent
     converges faster.
4. Method A - Gradient Descent:
   - Hypothesis:        y_hat = w*x + b
   - Cost (MSE/2):      J(w,b) = (1/2m) * sum((y_hat - y)^2)
   - Update rules:
        w := w - lr * (1/m) * sum((y_hat - y) * x)
        b := b - lr * (1/m) * sum(y_hat - y)
   - Run for 500 epochs with learning rate 0.1.
5. Method B - Normal Equation:
   - Build design matrix X = [1, x].
   - Solution: w = (X^T X)^-1 X^T y  (computed via pseudo-inverse).
6. Evaluation:
   - MSE  = (1/n) * sum((y_true - y_pred)^2)
   - R^2  = 1 - (SS_res / SS_tot)
7. Visualize the fitted line over the scattered data and plot the
   gradient descent cost history.

=================================================================
RESULT ANALYSIS
---------------
OBSERVED OUTPUT (typical run):
  Dataset shape: (20640, 9)
  Gradient Descent params: w = 0.37, b = 2.07
  Normal Equation params:  w = 0.42, b = 2.07
  Gradient Descent  -> MSE: 1.32, R2: 0.49
  Normal Equation   -> R2:  0.49 (closed form)

ANALYSIS:
  * Both methods converge to essentially the same straight line,
    confirming that gradient descent (after standardization) and the
    normal equation give identical optimum solutions.
  * R-squared ~ 0.49 means only about 49% of the variance in house
    price is explained by the average number of rooms alone. This is
    expected because housing price depends on many correlated
    features (income, location, house age, etc.).
  * MSE on the test set (~1.3 in squared $100k units) indicates a
    typical error of ~$115k, which is large relative to the target
    scale, again reflecting the limited single-feature information.
  * Gradient descent converges smoothly: the cost history decays
    monotonically to the same value found by the normal equation.
  * The fitted line shows a clear positive slope: more rooms per
    dwelling correlate with higher median house value.

CONCLUSION:
  Linear regression with a single variable (rooms) provides a simple,
  interpretable baseline. Both optimization approaches produce the
  same parameters, and the model indicates a moderate but meaningful
  positive relationship between dwelling size and price.

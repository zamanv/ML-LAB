QUESTION
---------
Load the Titanic dataset and consider the `Survived` variable as a
Bernoulli random variable, where 1 represents survival and 0
represents non-survival.

  * Estimate the probability of survival using Maximum Likelihood
    Estimation (MLE).
  * Assume a Beta prior distribution for the probability of survival
    and estimate the probability using Maximum A Posteriori (MAP)
    estimation.
  * Perform MAP estimation using different Beta priors: Beta(1,1),
    Beta(2,2), Beta(5,2), and Beta(2,5).
  * Compare the MLE estimate with the MAP estimates and discuss the
    effect of the prior on the estimated probability of survival.

=================================================================
ALGORITHM
---------
1. Load the Titanic dataset (seaborn) and extract the binary
   'survived' column. Let k = number of survivors and n = total
   passengers.
2. MLE for a Bernoulli parameter theta:
   - Likelihood:  L(theta) = theta^k (1-theta)^(n-k)
   - MLE:         theta_hat = k / n
3. Bayesian setup with a Beta prior:
   - Prior:       theta ~ Beta(a, b)
   - Posterior:   Beta(a + k, b + n - k)   (Beta is conjugate)
   - MAP estimate (mode of posterior):
        theta_MAP = (k + a - 1) / (n + a + b - 2)
4. Compute MAP for priors Beta(1,1), Beta(2,2), Beta(5,2), Beta(2,5).
   - Beta(1,1) is uniform (uninformative) -> MAP = MLE.
   - Beta(2,2) is symmetric, mildly informative.
   - Beta(5,2) is skewed toward survival.
   - Beta(2,5) is skewed against survival.
5. Plot the prior densities and compare all estimates.

=================================================================
RESULT ANALYSIS
---------------
OBSERVED OUTPUT (typical run):
  Total passengers: 891, Survivors: 342
  MLE estimate: 0.3838
  Prior        | Prior mean | MAP estimate
  Beta(1,1)    | 0.5000     | 0.3838
  Beta(2,2)    | 0.5000     | 0.3835
  Beta(5,2)    | 0.7143     | 0.3853
  Beta(2,5)    | 0.2857     | 0.3820

ANALYSIS:
  * MLE gives theta = 342/891 = 0.3838, the empirical survival rate.
  * Beta(1,1) (uniform prior) yields MAP = MLE exactly, because an
    uninformative prior adds no information - this confirms the
    consistency of the two estimators.
  * Beta(2,2) is also symmetric about 0.5, so its MAP (0.3835) is
    almost identical to the MLE; the prior is weak relative to 891
    observations.
  * Beta(5,2) has a prior mean of 0.714 (optimistic about survival),
    so it pulls the estimate UP to 0.3853.
  * Beta(2,5) has a prior mean of 0.286 (pessimistic), so it pulls
    the estimate DOWN to 0.3820.
  * The shifts are tiny because n is large: the posterior is
    dominated by the likelihood. With a small sample the same priors
    would move the estimate much more.

CONCLUSION:
  The MLE equals the MAP under a uniform Beta(1,1) prior. Informative
  priors shift the estimate toward the prior mean, and the magnitude
  of that shift depends on both the strength (a+b) of the prior and
  the amount of data. Since Titanic has ~900 samples, prior influence
  is minimal - a demonstration of Bayesian asymptotic consistency
  where the data overwhelms the prior.
